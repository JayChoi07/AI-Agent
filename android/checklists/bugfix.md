## 구현 순서
1. 재현 테스트 작성 — 결정 1의 위치
   → 검증: 수정 전에 이 테스트가 실패한다(실패 메시지를 기록) (R-30-01, R-30-06)
2. 원인 지점 최소 수정
   → 검증: 변경 파일이 원인 계층에 한정, 새 추상화 없음 (R-11-01, R-00-05)
3. 실패 경로 정리 (해당할 때)
   → 검증: 예외는 데이터 계층 경계에서 도메인 타입으로, `CancellationException`은 다시 던짐, 로그에 개인정보 없음 (R-23-05, R-22-10, R-23-09)
4. 재현 테스트 통과 확인
   → 검증: 1에서 실패하던 테스트가 통과 (R-30-01)
5. 인접 테스트 실행 — 결정 4의 범위
   → 검증: 기존 ViewModel 테스트·스크린샷 테스트 통과, 스크린샷 기준 이미지를 재기록하지 않음 (R-30-01, R-30-03, R-30-04)
6. ktlint·detekt·단위 테스트 실행
   → 검증: 0 이슈 (R-31-01)
